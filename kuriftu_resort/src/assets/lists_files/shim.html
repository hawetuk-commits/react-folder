Introduction & Overview

HTML lists organize related information into a readable structure. HTML provides three main list types: unordered lists (<ul>), ordered lists (<ol>), and description/definition lists (<dl>).
Overview: An unordered list uses bullets by default; an ordered list uses numbers or another sequence; a description list pairs each term with its description.

Unordered List: <ul>

Use an unordered list when the sequence of items is not important. Each item is placed inside an <li> element, and browsers usually display the items with bullet points.

  • <ul> means unordered list.
  • <li> means list item.
  • Changing the order of the items does not change the meaning.

Ordered List: <ol>

Use an ordered list when the sequence or ranking of items is important. Each item is enclosed within an <li> element, and browsers automatically display them with numbers or letters by default.

  • <ol> means ordered list.
  • <li> means list item.
  • Changing the order of items changes the logical meaning (e.g., instructions, rankings).

Ordered List Attributes

The <ol> tag supports several useful attributes to control numbering:

  • type: Specifies numbering type (e.g., "1", "A", "a", "I", "i").
  • start: Specifies the starting number value (e.g., start="5").
  • reversed: Counts downwards instead of upwards.

Description List: <dl>, <dt>, <dd>

A description list, formerly often called a definition list, is used to show terms and their descriptions. It uses three tags:

  • <dl> for the list.
  • <dt> for the term.
  • <dd> for the description.
Important: One <dt> can have more than one <dd>. Useful for glossaries, metadata, FAQs, and term–pairs.

Nested Lists

Lists can be placed inside other lists. This is useful for showing categories and subcategories.

Nesting allows developers to build clear hierarchical structures for site navigation and outlines.

Comparison Summary & Conclusion

List Type Primary Tags Best Use Case
Unordered List <ul>, <li> Items where order does not matter (e.g., navigation menus, bullet points).
Ordered List <ol>, <li> Sequential steps, rankings, or instructions where order matters.
Description List <dl>, <dt>, <dd> Glossaries, metadata pairs, FAQs, and term-definition structures.
