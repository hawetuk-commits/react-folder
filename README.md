# React Folder

This repository contains two React/Vite applications:

- `frontend/` - the frontend application.
- `kuriftu_resort/` - the Kuriftu Resort application.

## Run the frontend

```powershell
cd frontend
npm install
npm run dev
```

## Run Kuriftu Resort

```powershell
cd kuriftu_resort
npm install
npm run dev
```

Each application has its own dependencies and can be run independently.
